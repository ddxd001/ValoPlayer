## ACLOS 真实数据

只读检查了两组各 7 个账号缓存：按路径去重后 1,140 条录像，其中 1,008 个原文件存在；12,272 个有效事件（8,314 次击杀、3,958 次阵亡）。有录像的界面账号名称可能少于缓存文件数，因为空账号或相同显示昵称会合并为同一筛选名称。

事件时间映射与独立执行 WonderfulUI 的状态机逐条一致；官方 21 个账号及身份缓存的前后 SHA256 无变化。包含不完整依据的事件被隔离，没有被填充成猜测的标记。完整格式与验证依据见 [ACLOS.md](ACLOS.md)。

独立核心库真实扫描测试验证了两种目录添加顺序：均保留相同的 1,140 个 ID 和 12,272 个事件。初次扫描约 16 秒；无变化重扫约 254–323 毫秒。索引收藏及分类在重扫后仍保留。

## 尚未声称完成的验证

没有对每一种系统解码器、每一台外部电脑、每一种 ACLOS 版本或可变帧率寻帧精度做验收。NSIS 仅验证本机 Windows 11 x64 的安装、升级、快捷方式及启动；未验证缺失 WebView2 的全新系统、离线环境或代码签名，未实际卸载用户安装。未删除任何用户原始录像；回收站验证使用专门生成的临时文件。没有上传或分发个人录像与数据库。
